## 2. 로컬 서버 구동 검증

**산출물**: `정찬성/98.서버구동접속방법/서버구동접속정보.md`

- Docker로 PostgreSQL 16 컨테이너 기동 시도 → 로컬에 이미 다른 프로젝트의 `toyo-db` 컨테이너가 5432 포트를 쓰고 있어 충돌 → `semi-backend`는 **5555 포트**로 변경해 기동(`.env`의 `POSTGRES_PORT`/`DATABASE_URL`)

- `uvicorn app.main:app --reload`로 서버 기동, `/health`·`/docs`·`/dataviz` 접속 확인
- 위 전 과정과 트러블슈팅(포트 충돌, alembic 인코딩 오류, CSV 경로 오류)을 문서화

## 3. 산탄데르 고객만족 데이터 탐색 대시보드

**근거**: `정찬성/캐글산탄데르/캐글산탄데르.ipynb` (산탄데르 은행 고객만족 예측 EDA, 7개 셀짜리 초기 노트북)
**설계 문서**: `정찬성/99.TRD설계서_바이브코딩/SEMI TRD_메인화면.md`

노트북이 정적 셀 재실행 방식이라 조건을 바꿔가며 볼 수 없다는 문제를 해결하기 위해, 필터를 바꾸면 그래프·표가 즉시 갱신되는 웹 대시보드로 재구성했다.

만든 것:
- `app/domains/dataviz/` — CSV(76,020행×371열 중 5개 핵심 컬럼: `ID`,`var3`,`var15`,`var38`,`TARGET`)를 읽어 필터링/집계하는 도메인(DB 테이블이 아니라 CSV라 `models.py` 없음, `get_dataframe()`을 `Depends`로 노출해 테스트에서 교체 가능하게 설계)
- `app/static/dataviz/{index.html,app.js,style.css}` — TARGET/연령/지역 필터, var38 로그스케일 토글, 3종 차트(TARGET 분포, var38 히스토그램, 연령 만족/불만족 비교), 페이징 테이블
- API 7종: `/dataviz`, `/dataviz/summary`, `/dataviz/regions`, `/dataviz/records`, `/dataviz/chart/target-distribution`, `/dataviz/chart/var38-histogram`, `/dataviz/chart/age-distribution`
- `pyproject.toml`에 `pandas==3.0.5`, `numpy==2.5.2` 추가(기존 기술 스택 문서엔 없던 별도 의존성)
- `tests/test_dataviz.py` — 5행 표본 데이터로 10개 케이스 작성, 전체 통과

**검증**:
- 실제 76,020행 CSV로 서버를 띄워 전체 API curl 검증 (`unsatisfied_ratio=0.0396` 등 노트북 수치와 일치 확인)
- `claude-in-chrome`으로 브라우저에서 직접 필터 조작 — TARGET을 "불만족(1)"로 바꾸니 var38 히스토그램과 테이블(3,008건)이 실시간으로 갱신되는 것을 스크린샷으로 확인

**문서화**: `SEMI TRD_메인화면.md`에 화면 레이아웃(mermaid `flowchart`), 이벤트 흐름(mermaid `sequenceDiagram`), API 명세, AC, 테스트 시나리오(TC-DV1~10), 향후 개선 제안(var3 이상치 처리, 371개 컬럼 미탐색분, 모델링 결과 연동)까지 정리.

## 5. Render 배포 (진행 중)

### 겪은 문제와 해결

| 순서 | 문제 | 해결 |
|---|---|---|
| 1 | Render의 GitHub App이 `semi_project` 저장소에 접근 권한 없음(`toyo`만 연결돼 있었음) | GitHub → Render App 설정(`Repository access`)에서 `semi_project` 추가 |
| 2 | New Web Service 폼이 Go 프로젝트 기본값으로 채워짐 | Language를 Python 3로, Branch를 `SEMI_PROJECT`로, Build/Start Command를 프로젝트에 맞게 수정 |
| 3 | Root Directory(`정찬성/semi-backend`)가 "영문/숫자/`-_./`만 허용" 정규식에 걸려 거부됨(한글 폴더명 문제) | Root Directory는 비우고, Build/Start Command 안에서 `cd "정찬성/semi-backend" && ...`로 우회 |
| 4 | DB는 아직 연동하지 않기로 함(추후 Neon 등으로 연결 예정) | `DATABASE_URL`에 임시 placeholder(`postgresql+psycopg://unused:unused@localhost:5432/unused`)를 넣어 필수 필드 검증만 통과시킴, `Pre-Deploy Command`(`alembic upgrade head`)는 비워둠 — 실제 DB 연결 시 되돌려야 함 |

### 현재 상태

- 빌드/배포 자체는 성공 — `https://semi-project.onrender.com/dataviz` 접속 시 화면(HTML/CSS/JS)은 정상 렌더링됨
- 그러나 요약 카드·차트·테이블이 전부 빈 값(`-`, 0)으로 나옴 → 화면을 채우는 API 호출(`/dataviz/summary` 등)이 실패하고 있는 것으로 추정
- **다음 확인할 것**: `https://semi-project.onrender.com/dataviz/summary`를 직접 열어 에러 메시지 확인 + Render **Logs** 탭에서 실제 traceback 확인 → 원인 확정 후 조치 예정(현재 대화에서 진행 중)
