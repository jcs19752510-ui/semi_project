머신러닝 모델은 크게 여러 계열로 나눌 수 있습니다. 지금까지 다루신 분류 문제(Santander 고객 만족도 예측) 맥락에서 주로 쓰이는 것들 위주로 정리하면:

1. 트리 기반 앙상블 (Boosting/Bagging) — 지금 쓰신 XGBoost 계열

XGBoost (xgboost.XGBClassifier) — 지금 사용 중인 모델
LightGBM (lightgbm.LGBMClassifier) — XGBoost보다 빠르고 대용량 데이터에 강함
CatBoost (catboost.CatBoostClassifier) — 범주형(카테고리) 변수 처리에 강함
RandomForest (sklearn.ensemble.RandomForestClassifier) — 여러 트리를 독립적으로 만들어 평균/투표
GradientBoosting (sklearn.ensemble.GradientBoostingClassifier) — XGBoost의 원조격 sklearn 기본 구현

2. 선형 모델

LogisticRegression (sklearn.linear_model.LogisticRegression) — 가장 기본적인 분류 모델, 해석이 쉬움
SVM (sklearn.svm.SVC) — 마진 최대화 기반 분류

3. 단순 트리/거리 기반

DecisionTree (sklearn.tree.DecisionTreeClassifier) — 트리 1개, 앙상블의 기본 단위
KNN (sklearn.neighbors.KNeighborsClassifier) — 가까운 이웃들의 다수결로 분류

4. 딥러닝 계열

신경망(MLP) (sklearn.neural_network.MLPClassifier, 또는 TensorFlow/PyTorch) — 이미지, 텍스트 등 복잡한 패턴에 강함
